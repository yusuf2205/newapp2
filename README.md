# newapp2 — Telegram-бот учёта финансовых документов

Бот принимает фото и PDF чеков, счетов и договоров, распознаёт реквизиты и ведёт
таблицу в Google Sheets: новые договоры добавляет строкой, повторные оплаты
по уже существующему договору — суммирует и пересчитывает остаток.

## Структура

```
main.py            запуск бота (aiogram 3, long polling)
config.py          все настройки из .env
models.py          модель строки таблицы, парсинг и формат сумм
sheets.py          Google Sheets: сотрудники, запись, дедупликация
middlewares.py     подстановка карточки сотрудника (с кэшем на 10 мин)
keyboards.py       инлайн-кнопки
states.py          состояния FSM
handlers/
  registration.py  регистрация: ФИО + должность
  documents.py     приём файла → проект → карточка → запись
ocr/
  base.py          интерфейс, промпт извлечения, фабрика движков
  anthropic_engine.py / openai_engine.py / gemini_engine.py / tesseract_engine.py
```

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

### 1. Токен бота
Получите у [@BotFather](https://t.me/BotFather), впишите в `BOT_TOKEN`.

### 2. Google Sheets
1. В Google Cloud Console создайте проект, включите **Google Sheets API** и **Google Drive API**.
2. Создайте **сервисный аккаунт**, скачайте JSON-ключ, положите рядом как `credentials.json`.
   Если организация блокирует создание ключей сервисных аккаунтов
   (`iam.disableServiceAccountKeyCreation`) — создайте проект без организации/в другой
   организации, где эта политика не включена.
3. Откройте вашу таблицу и **дайте доступ на редактирование** почте вида
   `...@...iam.gserviceaccount.com` из этого JSON.
4. ID таблицы — из ссылки `docs.google.com/spreadsheets/d/`**`ID`**`/edit` → в `SPREADSHEET_ID`.

Листы «Данные» и «Сотрудники» создаются автоматически при первом запуске.

### 3. OCR-движок
Переключается одной строкой в `.env`:

| `OCR_ENGINE` | Что нужно | Комментарий |
|---|---|---|
| `anthropic` | `ANTHROPIC_API_KEY`, `pip install anthropic` | по умолчанию; PDF и фото читает нативно |
| `openai` | `OPENAI_API_KEY`, `pip install openai` | PDF рендерится в PNG постранично |
| `gemini` | `GEMINI_API_KEY`, `pip install google-genai` | дешёвый вариант, PDF нативно |
| `tesseract` | `pip install pytesseract` + `apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-uzb` | работает офлайн, но точность заметно ниже |

Добавить свой движок: наследуйте `OcrEngine` из `ocr/base.py`, реализуйте
`recognize(content, mime_type) -> dict` и зарегистрируйте в `get_engine()`.

### 4. Запуск

```bash
python main.py
```

## Как это работает

1. `/start` → если сотрудника нет в листе «Сотрудники», бот спрашивает ФИО и должность
   и сохраняет `[Telegram ID | ФИО | Должность | Дата | Статус]`.
2. Пользователь отправляет фото или PDF → OCR возвращает JSON по 7 полям.
3. Бот показывает кнопки выбора проекта (список берётся из `PROJECTS`, есть «➕ Другой»).
4. Карточка подтверждения → «✅ Подтвердить» / «✏️ Редактировать» / «❌ Отмена».
   В режиме редактирования можно поправить любое поле, суммы валидируются.
5. При записи бот ищет в колонке C договор с тем же номером (сравнение без учёта
   регистра, пробелов и знаков):
   - **нашёл** → прибавляет оплату к колонке «Оплачено», пересчитывает «Остаток»,
     дописывает пометку в «Примечание»;
   - **не нашёл** → добавляет новую строку из 11 колонок.
6. В ответ приходит номер строки в таблице.

Незаполненные поля пишутся как `[Не указано]` — модель не додумывает данные.
Суммы приводятся к виду `177800000.00`.

## Ограничения

- Bot API не отдаёт файлы больше 20 МБ — такие бот отклоняет.
- FSM хранится в памяти: после рестарта незавершённые карточки теряются.
  Для продакшена подключите `RedisStorage` в `main.py`.
- Альбом из нескольких фото обрабатывается как один документ (первое фото);
  многостраничные документы лучше присылать одним PDF (читаются первые 5 страниц).
- Одновременная запись защищена `asyncio.Lock` внутри процесса. Если запускать
  несколько инстансов бота на одну таблицу, дедупликация может разойтись.
